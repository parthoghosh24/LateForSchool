# LateForSchool

Late for school is a psychological horror text adventure where your end goal is to get the happy ending. There are 3 endings in the game. It is a classic text adventure with dynamic choices and inventory management.

## How to play?

Simply follow the on-screen prompts where you have to input one digit between 0-9. Some choices are dynamic based on whether you have matched the given condition or not.

## Why did I make this?

I made it because I wanted to teach myself C++. I chose C++ 17 (didn't got with the 23). My goal was to make a simple custom engine for the game. It is not very re-usable at this moment but I could see what I could pick and extract in case I decide to make another text adventure in the future. Some of the features are as follows:
* Custom engine with stack based game state management.
* Inventory management system.
* Dynamic responses based on the preconditions.
* Multiple endings.
* Graph like structure connecting various rooms and dependencies.
